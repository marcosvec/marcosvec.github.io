BikeSuite

Live demo (opens in a new tab) Source (opens in a new tab)

Overview

A browser-based demo of shop software for independent bike shops, informed by my experience at Merrick Bicycles, my family's bike shop. BikeSuite covers work orders, point of sale, inventory, and customer records. The demo runs on seeded data stored in the browser. There is no account server, database, or payment processor.

Key Features

  • Work orders: Track a repair from intake through pickup
  • Check-in: Open a work order when a bike is dropped off
  • Point of sale: A cart and checkout stored in the browser
  • Inventory: Stock, categories, and a reference-catalog import
  • Customers: Records with visit history from the demo data
  • Demo sign-in: Any value is accepted, including a blank one, and the password is not stored

Technical Details

Built with Next.js 16 (App Router, static export), TypeScript, and Tailwind CSS. The interface uses shadcn/ui. GitHub Pages serves the live demo at bikesuite.marcosvec.com. Source is on GitHub.

  • Tailwind CSS

Autonomous Boat: Propulsion & Steering Lead

Overview

Team Roboatics, RPI Introduction to Engineering Design (ENGR 2050), Spring 2026. Role: Propulsion & Steering Lead / Scribe. Designed and built the propulsion system for a debris-collecting catamaran, using differential thrust for steering without a rudder.

Drive System

  • Motors: 2× A2212 1000KV brushless DC (BLDC) motors
  • ESCs: LittleBee BLHeli-S 30A, configured in 3D (bidirectional) mode
  • Power: 3S LiPo battery
  • Housings: 3D-printed OpenThruster shells
  • Steering: Differential thrust, no rudder

Design Process

Bidirectional operation was a design requirement. The selected drive system paired brushless motors with bidirectional ESCs and OpenThruster housings so each thruster could run forward and reverse.

I designed a custom PETG thruster mount in Siemens NX with a bullet-nose profile, using a Boolean subtraction to form the mating geometry around the thruster housing. The mount connected the propulsion hardware to the boat; the OpenThruster housings were an existing design.

Motor windings were waterproofed with enamel coating; an early attempt using nail polish failed. Also caught early: M3 screws that were too long damaged the motor windings on initial assemblies. Shorter screws fixed it.

Bench Testing

For the classroom demonstration, we ran the motors in air and measured the speed of a pinwheel in the propeller airflow. This demonstrated operation of the propulsion system; it was not a measurement of underwater thrust or a validation of autonomous navigation.
